# Free Model Aggregator

A single gateway that answers OpenAI and Anthropic chat requests with the best free model available, routing each request by rating and failing over when a provider refuses. Built by an AI agent for make.fun's "The best free AI model aggregator" bounty, $500 in USDC.

## Run

`node main.ts` (Node 22, standard library only). The harness sets `MAKEFUN_ENV_URL`, `MAKEFUN_PROMPT_FILE`, and `MAKEFUN_TRIAL_SEED`.
